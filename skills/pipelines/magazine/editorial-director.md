# Editorial Director — Magazine Pipeline

## When to Use

After concept approval. Write every word in the issue as `editorial_copy`. The user approves
the copy before layout starts.

## Plan the issue first

Draft the running order (one line per page: page number, piece, target words) and confirm it
with the user — it becomes the flatplan. Rough capacity per 230×300 mm page at 9.6 pt body:

| Page type | Words |
|-----------|-------|
| Full text, 3 columns, no picture | 900–1000 |
| Text with one half-page picture | 450–550 |
| Feature opener (big picture, headline, dek) | 0–120 |
| Contents | 6–10 entries |
| News briefs page | 4–6 items × 80–120 |

Scale by area for other trims (A4 ≈ 0.9×, A5 ≈ 0.45×).

## Writing

- Every piece gets kicker, headline, dek, byline, body, 1–2 pull quotes (features), and a
  caption for each image slot. Captions say what the picture shows and why it matters.
- Write to `target_words` ±10%. Record the real `word_count`.
- Facts: cite `sources` for every factual claim about real people, organisations, laws, prices
  or dates. Mark `fact_check: checked` only after checking. Invented quotes from real people
  are forbidden; quote only from sources.
- Arabic copy: Modern Standard Arabic unless the brief asks for dialect; Latin digits 0-9;
  tashkeel only where a word would otherwise be misread.
- Cover lines: 3–5, each under 8 words, each pointing at a real page.

Present the copy as readable text (not JSON) for approval. Checkpoint `editorial`.
