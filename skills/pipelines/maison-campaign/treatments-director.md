# Treatments Director

Use `.agents/skills/fashion-direction/SKILL.md` under the Maison doctrine: write three treatments —
**Safe**, **Bold**, **Conceptual** — each with the scene, light, palette, cast (if any), styling and the
single line of copy. Render quick sketches where useful (`generative_art`). The human elects.
Then write the `shot_list`: per shot the purpose, framing, light, aspect ratio, route
(runway_mcp / pexels / pixabay / museum / drawing_series) and a Runway-ready prompt that names
qualities, never people or houses. Write `studio_proposal` for the elected treatment.
