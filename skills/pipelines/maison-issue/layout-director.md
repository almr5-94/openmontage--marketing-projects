# Layout Director — Maison Issue

Use `editorial_layout` with the **Maison grid preset** from house.yaml: wide margins (inner 22 mm,
outer 18, top 20, bottom 26), a quiet folio, the masthead constant across issues, the house's two
type families only.

Page sequence for a standard issue: cover object → contents → inventory spread → archive/contemporary
spread → drawing plate → feature opener → features → colophon → back cover.
- Spreads must face (even page on the left in LTR; the tool warns otherwise).
- One idea per page; let the empty space carry the luxury.
- `print_render` then the tool's checks (overflow, fonts, resolution). Show the grid overlay on request.
