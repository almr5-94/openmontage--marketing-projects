# House Brief Director

1. Load `maison/houses/<id>/house.yaml` (or create one with `maison_new_house` / `om maison house new`).
   Run `brand_lint` on it at once: an invented house must not borrow a real house's name or dress.
2. Agree the **theme** — one word or one idea (Water, Thread, Night, The Workshop).
3. The guest voice (a writer, a craftsperson, an archivist — invented unless the human names a real one
   who has agreed), languages (English, Arabic, both as separate editions), page count (a multiple of 4),
   trim, paper stock, finish.
4. Write `print_brief` and log each choice. Arabic is a native RTL edition, never a mirror of the English.
