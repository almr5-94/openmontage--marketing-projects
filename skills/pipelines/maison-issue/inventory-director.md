# Inventory Director

The issue is an **incomplete inventory** of the theme: a list of things, people, places and archives
that each show one facet of it.

1. Draft 20-40 candidates (the local planner model via `lib.local_models.chat`, or you). Each has a kind
   (story, object, place, person_profile, archive, craft, drawing), one line on why it belongs, and where
   possible an `archive_pair` (an old object or artwork to face a contemporary one) and a source hint.
2. Sequence the elected list story → character → influence.
3. Show the list; the human elects (or Claude elects and says so). Write `maison_inventory`.
Reject candidates that are product features in disguise: the theme carries the house, not a catalogue.
