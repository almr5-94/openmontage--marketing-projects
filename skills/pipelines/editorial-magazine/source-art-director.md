# Source Art Director — Editorial Magazine (stage `assets`)

Read `.agents/skills/art-sourcing/SKILL.md`.

## Order (free first, always)
1. Museum CC0 / public domain: `met_art`, `cleveland_art`, `rijks_art`, `aic_art` (search → fetch;
   fetch refuses anything not public domain).
2. `pexels_image`, then `pixabay_image` (licensed stock; record the licence).
3. The user's own files (licence `user-supplied`).

## Rules
- Search by object and material that carry the feeling, not by mood words.
- Plan for **no reuse** (AP-5): one source per placement across the whole issue. A crop, zoom,
  flip or recolour of a source counts as the same image.
- Full-bleed A4 needs ~2480×3508 px; smaller sources become fragments, insets or plates.
- Every file is recorded in `assets/PROVENANCE.json` by the tools. Reference images are looked
  at, never downloaded into the project.

## Write
`asset_manifest` listing each source with its licence and intended page.
