# Fashion Director — Editorial Magazine (optional)

Read `.agents/skills/fashion-direction/SKILL.md`.

1. Intake → a short visual-intelligence note (light, cloth, gesture, setting) in the issue's feeling.
2. Three treatments: Safe, Bold, Conceptual; the user picks one.
3. Cast notes and a shot list; one Runway-ready prompt per shot, each described by qualities,
   never by names. `brand_lint` must pass on `shots-<slug>.json` and every `*.prompt.txt`.
4. Route per shot: Runway MCP (elected, credits shown), or Pexels / Pixabay stock, or a museum work.
5. Face gate on every result that shows a person.

Write a schema-valid `shot_list`; save `briefs/shots-<slug>.json` and `briefs/<shot>.prompt.txt`.
