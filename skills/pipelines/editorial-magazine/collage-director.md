# Collage Director — Editorial Magazine

Read `.agents/skills/collage-composition/SKILL.md`. Tool: `collage`.

- Decide each page's text block first, then compose around it.
- Start from a `style` (`editorial_overlay`, `cutpaste`, `joiner`, `grid`, `mosaic`) with
  `layout_only: true`, edit the JSON, then render. One focal piece; odd counts; one light direction.
- Canvas = slot size at 300 dpi (`canvas: {width_mm, height_mm, dpi: 300}`).
- A collage that shows a person passes the face gate.
- The `.layout.json` beside each PNG is the editable record; provenance lists every parent.
