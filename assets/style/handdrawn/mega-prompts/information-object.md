# Mega-prompt 3 — the information object

A physical prop that exists in the scene is not the same as an explanatory overlay drawn for
the viewer. Decide which one you are asking for before anything else.

```text
[ISOLATED PHYSICAL INFORMATION PROP | EXPLANATORY DIAGRAM], [ASPECT RATIO], showing
[EXACT CONTENT PURPOSE]. Use [NUMBER OF CONTAINERS OR OBJECTS] arranged as [SPECIFIED LAYOUT].
Preserve these relationships exactly: [CONNECTION LIST, POINTER TARGETS OR PHYSICAL
ATTACHMENTS]. Reserve [TEXT AREAS] with [PADDING TARGET, 8-12% of card width]. The graphic must
read before any surface treatment is added.
```

## Family A — physical paper graphic

```text
hdx_paperfolk, enclosed fine contour drawing, shallow overlapping paper arrangement,
differentiated local-color fills, quiet mottled paper field. Object: [CARD | CERTIFICATE |
PINNED NOTE | PORTRAIT | SCREEN PROP]. If pinned, show the pin-to-paper attachment and
intentional string routes. Lettering role: [TYPEWRITER LABEL | BOLD IRREGULAR UPPERCASE], exact
wording verified separately. Keep board content (in the world) distinct from an external label.
```

## Family B — graphic prop

```text
hdx_incise, opaque black silhouette construction, high-value incised interior structure. Object:
[BOOK | VESSEL | TABLET | SIGN | OTHER]. Decisive silhouette, selected incised structural marks,
a small scene-compatible accent palette. No glossy bevels. A newly invented interface panel is a
derivative design and needs separate approval - the references do not establish one.
```

## Family C — scientific graphic

```text
hdx_biotext, irregular hand-shaped diagram discs, dark-green scientific icon fills,
cream-on-blue diagram contrast, connectors behind pictogram containers. Mode: [NETWORK |
MAGNIFICATION CALLOUT]. For a network, follow the supplied edge list exactly and keep a visible
rim inside each disc. For a callout, tie each enlarged window to its source organism with one
unambiguous pointer and show [SPECIFIED INTERNAL STRUCTURE].
```

## Always

```text
Exclude unrelated interface decoration, random arrows, unintended duplicate nodes, platform
marks and accidental capture text. Do not add any factual relationship that was not specified.
```

A generated diagram is checked against its intended connection list by a human. Style matching
cannot make a wrong graph right.
