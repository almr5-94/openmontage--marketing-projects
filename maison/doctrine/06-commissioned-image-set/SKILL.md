# 06. Commissioned image set

Each issue gets a deliberately built, cohesive image set: the same light, palette, paper and hand. Never a pile of unrelated pictures.

## Do

- Write one commission per story before producing any image: light, palette, hand/medium, paper texture, crop habits.
- Produce free first (CC0 museum art, Pexels/Pixabay, generative drawing), then elected Runway generations from micro-briefs.
- Run a consistency check: a contact sheet of the set, judged against its commission; outliers are redone, never kept for convenience.

## Check (the critic asks)

- Shuffle the set's thumbnails: could a stranger tell which story each belongs to, and that they all belong to this issue?

Scored in `maison/critique/rubric.md` under: cohesion, craft.

Never name, quote the look of, or recreate a real house: describe qualities instead (`brand_lint` blocks names).
