# 04. Past informs present

Pair archive and old-master material (CC0 museum art) with contemporary work in the same spread, so each reads the other differently.

## Do

- Every issue has at least one archive/contemporary spread: a CC0 museum work on one page, a contemporary drawing, photograph or object on the facing page.
- The pairing is chosen for a shared quality (a gesture, a material, a geometry), not a shared subject label.
- Captions name both works fully: title, maker, date, collection, licence.

## Check (the critic asks)

- What does the old work make you see in the new one, and the reverse? Write it in one sentence; if you cannot, change the pair.

Scored in `maison/critique/rubric.md` under: archive_dialogue.

Never name, quote the look of, or recreate a real house: describe qualities instead (`brand_lint` blocks names).
