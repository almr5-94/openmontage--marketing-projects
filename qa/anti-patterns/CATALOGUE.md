# Anti-pattern catalogue: the "made by an AI" tells

These are **negative examples only.** They're crops from a failed AI-made issue ("Sard Private Editions" v0).
- Never use them as style references or image-generation inputs.
- The critic compares every page against them.
- Codes match section 3c of the integration prompt.

## Forensic facts about the source issue
| Fact | Value |
|---|---|
| Length and format | 120 pages, A4 |

## What would have passed instead (direction, not a template)
- **01:** one line of native literary Arabic set in a real display face. The contact promise moves to the colophon.
- **02 / 21:** the arch as a physical object (carved stone, engraved brass, inlaid wood) photographed in raking light, or a gouache plate from an elected drawing series.
- **05 / 12 / 13:** real photography or an elected generation of the actual object (a leather folio, a brass desk clock, an archive box) from a full micro-brief. Each image used once.
- **03 / 07 / 11 / 15 / 19:** no diagram at all. A single image and a single sentence carry the idea, and folios follow the magazine's typographic system.
